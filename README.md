# HKU Robotics 2026

Robotics learning, coursework and research portfolio at The University of Hong Kong (HKU).

## 🎯 Objective

This repository is used to organize my robotics learning progress during my MSc studies at HKU.

Main areas include:

- ROS 2 (Robot Operating System 2，机器人操作系统 2)
- Robotics fundamentals（机器人学基础）
- Robot control（机器人控制）
- Perception（机器人感知）
- Locomotion（机器人运动与步态控制）
- Course projects（课程项目）
- Research and dissertation preparation（科研与毕业论文准备）
